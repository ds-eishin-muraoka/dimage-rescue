- 単一HTML（`index.html`）・依存なし・スマホ縦持ち推奨
- 💣「触るな危険」（赤ラベル）をタップすると障害発生 −50点＆コンボ0
- 🤖AI開発支援が出たら5秒間ポイント2倍（AI支援モード）
- 逃すと「塩漬けに…」でコンボ切れ
- ゲーム終了後に会社紹介ポップアップ／下部に SmartMigration AI のPRバナー常時表示
- ベストスコアは localStorage 保存
